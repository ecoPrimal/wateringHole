### Proton = Membrane
- **Charge**: positive (selectivity — curves, not walls)
  - Sigmoid σ(x) for throttle pressure (gradual, not binary DROP)

- **Atomic number**: defines identity (how many protons = what element you are)
- **Components**: caddy (face), skunky (thymus), opsonize (classification), tower services

### Neutron = Discuss/Messaging
- **Charge**: zero (no bias — anyone can speak, no account required)
- **Mass**: heavy (discussions persist, messages have weight)
- **Stability**: stable only IN the nucleus (free neutrons decay in ~15 min)
- **Binding**: neutrons bind protons together — discussions bind membrane surfaces together
- **Components**: neutron.primals.eco, membrane-discuss.js, /api/discuss, chat/notes/inbox/reminders

### Electron = Human
- **Charge**: negative (the human perspective — questions, doubts, probes, tests)
- **Mass**: light (arrives, orbits, may leave — ephemeral presence)
- **Quantized**: energy levels = epitope types
  - Ground state = visitor (just looking)
  - First excited = observer (reading, dwelling)
  - Second excited = coder (contributing, building)
  - Ionization = sovereign (fully engaged, self-sustaining orbit)
- **Bonds**: electrons shared between atoms create molecules — humans connecting between membranes create the mesh

### Neutrino = Squirrel + Chipmunk
- **Charge**: null (no interaction with the data, pure observation)
- **Mass**: nearly zero (minimal resource footprint — squirrel-watch is 24MB)
- **Interaction**: weak force only (the weakest of the four forces — just enough to detect)
- **Passes through**: squirrel sees 142K requests but touches none. Chipmunk tracks presence but never intervenes.
- **Three flavors**: electron neutrino (observes humans), muon neutrino (observes fleet), tau neutrino (observes membrane itself)
- **Oscillation**: neutrinos change flavor as they travel — squirrel shifts between observing humans, fleet, and membrane

## The Braid Build Pattern

Zola rebuilds all 432 pages every time — 141 seconds, 260MB RAM, on a 2GB VPS.
Most 15-minute cycles have ZERO content changes. Pure waste.

**Before**: full 0D snapshot every cycle (rebuild everything regardless)

**After**: 1D braid trajectory (track what changed, build only when needed)

```
eastgate ──push──→ forgejo ──cascade──→ golgi
northgate ─push──→ forgejo ──cascade──→ golgi
                                          │
                                    zola-braid.sh
                                          │
                              ┌───── HEAD == last? ─────┐
                              │                         │
                            YES                        NO
                              │                         │
                            SKIP                  what changed?
                          (0 CPU)                       │
                                          ┌─────────────┤
                                          │             │
                                    static only    content/template
                                          │             │
                                      rsync          zola build
                                    (instant)        (141 sec)
                                          │             │
                                          └──── atomic swap ────┘
```

**Result**: ~95% of cascade cycles now SKIP (sub-second, zero RAM).
Only actual content changes trigger the 141-second zola build.
Static file changes (llms.txt, images) bypass zola entirely.

The VPS stops gasping. The proton conserves its mass.

### Files

- `/opt/membrane/zola-braid.sh` — the braid build script
- `/run/membrane/zola-last-built` — tracks last-built commit hash
- `/etc/systemd/system/cascade-sense.service.d/zola-rebuild.conf` — wires braid into cascade
- `MEMBRANE_ZOLA_AUTO_BUILD=0` — membrane binary's internal build disabled (braid handles it)
